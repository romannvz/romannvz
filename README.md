# Привет! 👋

Я дипломированный разработчик программного обеспечения с более чем 3-летним опытом разработки и поддержки веб-приложений. В настоящий момент devops-backend-dev серии продуктов для городских пассажироперевозок: системы для перевозчиков, аналитика для органов исполнительной власти, информирование пассажиров и населения.  
Всегда открыт новым технологиям, создаю качественные, поддерживаемые и масштабируемые продукты.

## 🚀 Чем занимаюсь прямо сейчас

- **Real-time мониторинг транспорта:** приём GPS (Wialon IPS), WebSocket-трансляция положения городского транспорта, прогресс по рейсам, посещение остановочных пунктов, соблюдение расписания, заполненность транспорта через MQTT-сигналы CameraCount
- **BLE-инфраструктура:** пассажиропоток, фиксация прибытия на остановку и live-заполненность салона по сигналам маяков, ожидание на остановках, полевое тестирование
- **Расписания и отчётность:** импорт городских расписаний движения автобусов с интерполяцией времени по контрольным пунктам, регуляторные формы отчётности
- **Платежи и интеграции:** онлайн-оплата через банки, уведомления (FCM), интеграция с API Яндекс.Доставки, карты 2GIS
- **Аналитика и производительность:** графики пассажиропотока, выявление загруженных рейсов и наиболее популярных участков маршрутов; Redis, нагрузочные ступенчатые тестирования (Locust, k6), оптимизация производительности и повышение пропускной способности
- **DevOps:** GitLab CI/CD (пайплайны и джобы в YAML, раннеры, container registry), версионирование, деплой, настройка серверов и доступов по SSH
